# Simple Portfolio Website

## Overview

This is a basic Personal Portfolio Website developed using HTML for learning and practicing fundamental web development concepts. The project demonstrates how to structure a web page and organize personal information using HTML elements.

---

## Features

- About Me section
- Skills section
- Projects section
- Contact information
- Simple and clean design

---

## Technologies Used

- HTML5

---

## Purpose

This project was created for **learning purposes** to understand:

- HTML page structure
- Headings, paragraphs, and lists
- Hyperlinks and navigation
- Organizing content on web pages
- Basic website development
